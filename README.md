# Amazon Sales Analysis Dashboard | Power BI

An interactive sales analysis dashboard built using Microsoft Power BI to explore sales performance, product categories, and product trends.

## Dashboard Preview

![Amazon Sales Dashboard](Screenshot%202026-10-20%20124619.png)

## Project Overview

This project focuses on presenting sales data through an interactive dashboard, making it easier to explore key performance indicators and compare product performance across categories and time periods.

## Key Features

- **Sales KPIs:** YTD Sales, QTD Sales, YTD Products Sold, and YTD Reviews.
- **Monthly Sales Analysis:** Visualizes sales trends across the months of the year.
- **Weekly Sales Analysis:** Examines sales patterns by week.
- **Product Category Analysis:** Compares YTD Sales, QTD Sales, and percentage contribution by category.
- **Top 5 Products by Sales:** Highlights products ranked by YTD Sales.
- **Top 5 Products by Reviews:** Compares products based on YTD Reviews.
- **Interactive Filters:** Allows users to filter the dashboard by product category and quarter.
